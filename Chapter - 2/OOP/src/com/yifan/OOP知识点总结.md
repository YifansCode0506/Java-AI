## 1. `oopTest1`：类和对象入门

涉及文件：

- `oopTest1/Dog.java`
- `oopTest1/Test.java`

核心知识点：

- 使用类描述现实中的事物，例如用 `Dog` 类表示狗。
- 类中可以定义成员变量，例如 `name`、`age`、`weight`、`color`。
- 使用 `new Dog()` 创建对象。
- 通过 `对象名.属性名` 给对象属性赋值。
- 不同对象拥有各自独立的数据，例如 `d1` 和 `d2` 分别表示两只不同的狗。

这一部分的重点是理解：类是模板，对象是根据模板创建出来的具体实例。

## 5. `oopSet1`：封装和 `private`

涉及文件：

- `oopSet1/Dog.java`
- `oopSet1/Test.java`

核心知识点：

- 使用 `private` 修饰成员变量，限制外部类直接访问。
- 外部类不能再通过 `d.name = ...` 直接修改私有属性。
- 通过 `setName`、`getName`、`setAge`、`getAge` 方法间接访问成员变量。
- `setAge` 中加入年龄范围判断，体现封装的好处：可以控制数据是否合法。
- `eat()` 方法使用对象内部的 `age` 和 `name` 输出行为描述。

这一部分从“对象属性可以随便改”推进到“对象应该保护自己的数据”，这是封装思想的起点。

涉及文件：

- `oopSet3/Student.java`

核心知识点：

- 为 `name`、`age`、`height`、`weight` 分别提供 `get/set` 方法。

## 7. `oopThis`：`this` 关键字和就近原则

涉及文件：

- `oopThis/This.java`
- `oopThis/Test.java`

核心知识点：

- 成员变量和局部变量可以同名。
- Java 变量访问遵循就近原则：方法中直接写 `age` 时，优先访问局部变量。
- `this.age` 明确表示当前对象的成员变量。
- 如果成员变量没有手动赋值，`int` 类型默认值是 `0`。

这一部分专门解释为什么 setter 方法中常写 `this.name = name;`。左边的 `this.name` 是成员变量，右边的 `name` 是形参。

## 8. `oopStru1`：构造方法和 JavaBean

涉及文件：

- `oopStru1/Student.java`
- `oopStru1/Test.java`

核心知识点：

- 构造方法用于创建对象时初始化对象。
- 无参构造方法：`public Student()`。
- 带参构造方法：`public Student(String name, int age, String gender, int height)`。
- 构造方法没有返回值类型，方法名必须和类名完全一致。
- 一个类中可以同时存在无参构造和带参构造，这叫构造方法重载。
- 如果没有手写任何构造方法，系统会提供默认无参构造。
- 如果手写了任意构造方法，系统不再自动提供默认无参构造。
- JavaBean 类通常包含私有成员变量、无参构造、带全部参数的构造、以及对应的 `get/set` 方法。

这一部分把前面的封装和 `this` 结合起来，进入更规范的类设计写法。

## 知识点递进关系

整体学习路径可以概括为：

1. 先学习如何定义类，用成员变量描述对象属性。
2. 再学习如何通过 `new` 创建对象，并给不同对象保存不同数据。
3. 接着给类添加成员方法，让对象不仅有属性，也有行为。
4. 然后引入 `private`，理解直接暴露属性会破坏数据安全。
5. 再使用 `get/set` 方法控制属性读写，并在 setter 中加入合法性判断。
6. 随后学习 `this`，解决成员变量和局部变量同名时的访问问题。
7. 最后学习构造方法，在对象创建时完成初始化。
8. 将 `private`、构造方法、`get/set`、成员方法组合起来，形成标准 JavaBean 写法。

## 最终形成的 OOP 理解

这些代码从最基础的对象创建开始，逐步引导到规范的类设计：

- 类负责描述一类事物。
- 对象是类的具体实例。
- 成员变量表示对象的属性。
- 成员方法表示对象的行为。
- `private` 保护对象内部数据。
- `get/set` 提供可控的数据访问方式。
- `this` 表示当前对象。
- 构造方法负责对象初始化。
- JavaBean 是一种常见、规范、可复用的类写法。

因此，这组代码的学习主线是：从“会创建对象”逐步走向“会设计一个封装良好的类”。
